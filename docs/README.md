## GitHub Wiki

Para habilitar a GitHub Wiki:

1. Acesse: `https://github.com/Lupahlinda/Projeto-ETL-COMEXStat-2025/settings`
2. Role até a seção **Features**
3. Marque a opção **Wikis**
4. Clique em **Save**

Após habilitar, os arquivos desta pasta podem ser copiados para a wiki.
