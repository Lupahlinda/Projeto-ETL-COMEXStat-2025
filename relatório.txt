================================================================================
INTRODUÇÃO
================================================================================

Este relatório apresenta a abordagem metodológica empregada no desenvolvimento
do projeto ETL (Extract, Transform, Load) para análise de dados de exportação
brasileiros do COMEX Stat, com foco no ano de 2025. O projeto foi estruturado
para garantir robustez, escalabilidade e conformidade com os requisitos
acadêmicos de Business Intelligence e Data Warehouse.

OBJETIVOS DA MODELAGEM

    1. COMPREENSÃO ESTRUTURAL: Mapeamento completo da base de dados COMEX Stat
    2. PROCESSAMENTO EFICIENTE: Implementação de pipeline ETL otimizado
    3. ANÁLISE PREDITIVA: Desenvolvimento de modelos para previsão de valores de exportação
    4. CONFORMIDADE REGULATÓRIA: Atendimento 100% dos requisitos obrigatórios

ARQUITETURA DO SISTEMA

CAMADA DE EXTRAÇÃO (EXTRACT)

A camada de extração foi projetada para garantir a integridade e 
confiabilidade dos dados brutos:

    • FONTES DE DADOS: API REST do Ministério da Economia - COMEX Stat
    • PROTOCOLOS: HTTPS com tratamento de certificados SSL
    • VALIDAÇÃO: Verificação automática de integridade dos arquivos
    • CACHE LOCAL: Armazenamento em pasta /input para processamento offline

IMPLEMENTAÇÃO TÉCNICA:
def baixar_csv(url, filename):
    response = requests.get(url, verify=False)
    if response.status_code == 200:
        with open(f"input/{filename}", "wb") as file:
            file.write(response.content)

CAMADA DE TRANSFORMAÇÃO (TRANSFORM)

A transformação foi estruturada em múltiplas etapas para garantir a qualidade 
dos dados:

    1. VALIDAÇÃO DE INTEGRIDADE
    • VALIDAÇÃO CRUZADA: Comparação com totais de conferência oficiais
    • MÉTRICAS: Número de linhas, valor FOB total, peso líquido total
    • ASSERTIVAS: Garantia matemática da consistência dos dados


    2. ENRIQUECIMENTO SEMÂNTICO
Implementação de dicionários de expansão para tradução de códigos:

    • dict_country.csv: Mapeamento código → nome do país
    • dict_ncm_product.csv: Mapeamento NCM → descrição do produto  
    • dict_urf.csv: Mapeamento código → nome da URF
    • dict_sg_uf.csv: Mapeamento sigla → nome do estado
    • dict_bloco.csv: Mapeamento código → bloco econômico
    • dict_municipio.csv: Mapeamento código → nome do município
    • dict_via.csv: Mapeamento código → tipo de via de transporte

RACIONAL: Transformação de códigos técnicos em informações 
compreensíveis facilita análise e geração de relatórios.

    3. FILTRAGEM ESPECÍFICA
Desenvolvimento de filtro focalizado no agronegócio:

    • CRITÉRIOS: Produtos relevantes para o setor agrícola e agroindustrial
    • OBJETIVO: Eliminação de ruídos e concentração em dados relevantes
    • IMPACTO: Melhora da precisão do modelo preditivo

CAMADA DE CARGA (LOAD)

A camada de carga foi implementada seguindo as melhores práticas de engenharia 
de dados:

MODELO DE DADOS RELACIONAL
Implementação das 9 tabelas obrigatórias com normalização 3FN:

    1.  IMPORTAÇÃO: Dados de importação (simulada para este projeto)
    2.  EXPORTAÇÃO: Dados de exportação brasileira (tabela principal)
    3.  NCM: Produtos e classificações Mercosul
    4.  PAÍSES: Países de destino/origem com blocos econômicos
    5.  BLOCOS: Blocos econômicos internacionais
    6.  MUNICÍPIOS: Municípios brasileiros
    7.  ESTADOS: Estados brasileiros
    8.  VIA: Vias de transporte
    9.  URF: Unidades de Despacho Aduaneiro

RELACIONAMENTOS
    • CHAVES PRIMÁRIAS COMPOSTAS: Nas tabelas de transações
    • CHAVES ESTRANGEIRAS: Integridade referencial garantida
    • NORMALIZAÇÃO: Eliminação de redundâncias e anomalias


MODELAGEM PREDITIVA

ABORDAGEM METODOLÓGICA

1. SELEÇÃO DE VARIÁVEIS
- VARIÁVEL ALVO: VL_FOB (Valor FOB em dólares)
- FEATURES PREDITORAS: 
  - CO_ANO, CO_MES (temporais)
  - CO_NCM (produto)
  - CO_PAIS (destino)
  - SG_UF_NCM (origem)
  - CO_VIA (transporte)
  - CO_URF (despacho)
  - QT_ESTAT (quantidade)
  - KG_LIQUIDO (peso)

2. PRÉ-PROCESSAMENTO
- ENCODING DE VARIÁVEIS CATEGÓRICAS: OneHotEncoder para países, estados, vias
- NORMALIZAÇÃO: Padronização de escalas numéricas
- DIVISÃO: Treino/Teste (80/20)

3. ALGORITMO DE REGRESSÃO
- MODELO: Regressão Linear Múltipla
- BIBLIOTECA: scikit-learn
- OTIMIZAÇÃO: GridSearchCV para hiperparâmetros

4. AVALIAÇÃO DE DESEMPENHO
- MSE (MEAN SQUARED ERROR): Sensibilidade a outliers
- MAE (MEAN ABSOLUTE ERROR): Interpretabilidade do erro médio
- VISUALIZAÇÃO: Gráfico de dispersão previsão vs real

CONCLUSÕES

O Projeto ETL COMEX Stat 2025 foi desenvolvido com sucesso, atendendo a todos

transformações, análise preditiva e modelagem dimensional Star Schema para
suportar dashboards analíticos no Power BI.
